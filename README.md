# บันทึกยอดโอน — EDC Glass

แอปบันทึกยอดโอนถุงเงินหน้าลานปั๊ม ทำงานในเบราว์เซอร์ล้วน ไม่ต้องมีเซิร์ฟเวอร์ ข้อมูลเก็บในเครื่อง (localStorage)

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด |
| `manifest.json` | ข้อมูลแอปสำหรับติดตั้งลงหน้าจอโฮม |
| `sw.js` | Service Worker ทำให้เปิดใช้ได้แม้เน็ตหลุด |
| `icon-192.png` / `icon-512.png` | ไอคอนแอป |
| `icon-512-maskable.png` | ไอคอนแบบ maskable สำหรับ Android |
| `apple-touch-icon.png` | ไอคอนสำหรับ iPhone/iPad |
| `favicon-32.png` | ไอคอนบนแท็บเบราว์เซอร์ |
| `.nojekyll` | บอก GitHub Pages ไม่ต้องประมวลผลด้วย Jekyll |

## วิธีอัปโหลดขึ้น GitHub

### วิธีที่ 1 — ผ่านเว็บ (ง่ายสุด ไม่ต้องลงโปรแกรม)

1. เข้า https://github.com แล้วล็อกอิน (ถ้ายังไม่มีบัญชี กด Sign up)
2. กดปุ่ม **+** มุมขวาบน → **New repository**
3. ตั้งค่า
   - Repository name: `pump-app`
   - เลือก **Public** (ถ้าเลือก Private จะเปิด GitHub Pages ฟรีไม่ได้)
   - **ไม่ต้อง** ติ๊ก Add a README
   - กด **Create repository**
4. ในหน้า repo ที่ว่างเปล่า กดลิงก์ **uploading an existing file**
5. ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (index.html, manifest.json, sw.js, ไฟล์ .png ทุกตัว, README.md) ลงไปพร้อมกัน
   - ถ้าไฟล์ `.nojekyll` ลากไม่ขึ้นเพราะขึ้นต้นด้วยจุด ให้ข้ามได้ ไม่กระทบการใช้งาน
6. ช่องล่างพิมพ์ข้อความอะไรก็ได้ เช่น `first upload` → กด **Commit changes**

### วิธีที่ 2 — ผ่าน Git บนคอมพิวเตอร์

```bash
cd pump-app
git init
git add .
git commit -m "first upload"
git branch -M main
git remote add origin https://github.com/ชื่อผู้ใช้ของคุณ/pump-app.git
git push -u origin main
```

## วิธีเปิด GitHub Pages ให้ได้ลิงก์ใช้งานจริง

1. ในหน้า repo กดแท็บ **Settings**
2. เมนูซ้ายมือ เลือก **Pages**
3. หัวข้อ **Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: **main** และโฟลเดอร์ **/ (root)**
   - กด **Save**
4. รอประมาณ 1–3 นาที แล้วรีเฟรชหน้า จะมีลิงก์ขึ้นมาแบบนี้

```
https://ชื่อผู้ใช้ของคุณ.github.io/pump-app/
```

ลิงก์นี้เป็น **https** ซึ่งจำเป็นมาก เพราะกล้องสแกนบาร์โค้ดและการติดตั้งลงหน้าจอโฮมจะทำงานได้เฉพาะบน https เท่านั้น

> เวลาแก้ไขไฟล์ทีหลัง ให้อัปโหลดทับไฟล์เดิมใน repo แล้วรอ 1–2 นาที ลิงก์เดิมจะอัปเดตเอง
> ถ้าหน้าจอยังเป็นของเก่า ให้เปลี่ยนเลข `CACHE = 'pump-transfer-v2'` ใน `sw.js` เป็น `v3` ก่อนอัปโหลด แล้วปิดเปิดแอปใหม่

## วิธีติดตั้งเป็นแอปบนมือถือ

### Android (Chrome)

1. เปิดลิงก์ GitHub Pages ใน Chrome
2. กดจุดสามจุดมุมขวาบน → **ติดตั้งแอป** หรือ **เพิ่มไปยังหน้าจอหลัก**
   - ถ้าไม่เห็นเมนูนี้ ลองรอสัก 10 วินาทีแล้วรีเฟรช 1 ครั้ง (Chrome ต้องโหลด Service Worker ให้เสร็จก่อน)
3. กด **ติดตั้ง** — ไอคอนหัวจ่ายน้ำมันจะไปอยู่บนหน้าจอโฮม
4. เปิดจากไอคอนนั้น จะได้หน้าจอเต็มแบบแอป ไม่มีแถบ URL ไม่ปนกับแท็บอื่น เหมือนเครื่อง EDC

### iPhone / iPad (Safari)

บน iOS ต้องใช้ Safari เท่านั้น Chrome บน iOS ติดตั้งไม่ได้

1. เปิดลิงก์ใน **Safari**
2. กดปุ่มแชร์ (สี่เหลี่ยมลูกศรขึ้น) ด้านล่าง
3. เลื่อนหาแล้วกด **เพิ่มไปยังหน้าจอโฮม** → **เพิ่ม**

### คอมพิวเตอร์ (Chrome / Edge)

เปิดลิงก์ แล้วกดไอคอนรูปจอคอมพร้อมลูกศรที่ปลายช่อง URL → **ติดตั้ง**

## การอนุญาตกล้องสำหรับสแกนบาร์โค้ด 16 หลัก

- ต้องเปิดผ่าน **https** เท่านั้น (ลิงก์ GitHub Pages ผ่านเงื่อนไขนี้แล้ว)
- ครั้งแรกที่กดปุ่มสแกน Chrome จะถามสิทธิ์กล้อง ให้กด **อนุญาต**
- ถ้าเผลอกดบล็อกไปแล้ว: กดไอคอนแม่กุญแจ (หรือรูปสไลเดอร์) ข้างช่อง URL → **สิทธิ์ / Permissions** → เปิด **กล้อง** → รีเฟรชหน้า
- เครื่องที่ไม่มี `BarcodeDetector` ในตัว (iPhone และ Firefox) แอปจะโหลดตัวถอดรหัส ZXing มาใช้แทนอัตโนมัติ ครั้งแรกต้องต่อเน็ต

## การกรอกตัวเลขด้วยคีย์แพดในแอป

ไม่มีการเรียกคีย์บอร์ดของเครื่องอีกต่อไป ทั้งสามช่องใช้ **คีย์แพดเต็มจอที่สร้างในแอปเอง** (ปุ่ม 0–9 มีช่องว่างสมดุล ไม่เบียดกัน):

- จำนวนเงิน (บาท) — แตะช่องยอดแล้วกรอก รวมจุดทศนิยมและปุ่มลัด +10 … +1,000
- เบอร์โทร 10 หลัก
- เลขบัตรสมาชิก 16 หลัก (มีปุ่มสแกนบาร์โค้ด)

ปุ่มยกเลิก / ตกลงใช้งานได้ปกติทุกกรณี

## Export ข้อมูล

หน้ารายการมีปุ่ม **Export** ปุ่มเดียว — ดาวน์โหลดไฟล์ `.zip` ข้างในมีทั้ง Excel 2 ชีต (สรุปยอดโอน + วิเคราะห์เชิงลึก) และรูปสลิปทุกใบในโฟลเดอร์ `slips/` ส่งให้บัญชี/หัวหน้างานชุดเดียวจบ

ปุ่ม **ลบเก่า** อยู่ล่างสุดของหน้ารายการ เป็นปุ่มเล็กไม่รบกวนสายตา

ครั้งแรกที่กด Export ต้องมีเน็ตชั่วครู่ เพื่อโหลดไลบรารี SheetJS / JSZip จาก CDN

## ข้อมูลและการสำรอง

- ข้อมูลทั้งหมดเก็บใน **IndexedDB** ของเบราว์เซอร์เครื่องนั้น (ถ้าเบราว์เซอร์เก่ามากไม่รองรับ จะสำรองไปที่ localStorage อัตโนมัติ) ไม่มีการส่งออกไปเซิร์ฟเวอร์ไหน
- IndexedDB ไม่มีเพดานตายตัวที่ 5-10MB แบบ localStorage จึงเก็บรูปสลิปความละเอียดสูง (ยาวสุด 1800px คุณภาพ 92%) ได้สบาย ขึ้นอยู่กับพื้นที่ว่างจริงของเครื่อง
- ถ้าล้างข้อมูลเบราว์เซอร์หรือถอนการติดตั้งแอป ข้อมูลจะหายไป จึงควรกด **Excel** หรือ **ZIP รวมรูป** เก็บไฟล์สรุปไว้เป็นระยะ
- ปุ่ม **ลบเก่า** ในหน้ารายการ ใช้ลบข้อมูลที่เก่ากว่าที่กำหนด (7 / 30 / 90 วัน หรือกำหนดวันที่เอง) โดยไม่กระทบรายการล่าสุด ระบบจะโชว์จำนวนรายการที่จะลบให้ดูก่อนกดยืนยันเสมอ
